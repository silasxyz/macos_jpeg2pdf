# jpeg2pdf for macos
Schlanke macOS-App, die JPEG- und HEIC-Bilder per Drag &amp; Drop in PDF-Dateien umwandelt. Einfache Bedienung, Installation und erste Nutzung in wenigen Minuten möglich. Funktioniert 100% offline, ohne Internetverbindung oder Cloud-Upload – alle Konvertierungen laufen lokal auf dem Gerät, keine Daten verlassen den Mac.
